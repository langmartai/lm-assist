Assign a node

A name that does not exist yet creates that cluster. Placement, leader election and registry sync are all cluster-scoped, so moving a node re-homes it for the whole fleet — the button asks once before it fires.
The node list is the machine registry and the cluster map together. registry only means the fleet has no cluster record for that node: while it stays offline the server cannot resolve it and answers BAD_NODE, which this page reports as it comes.
Select a cluster on the left to see its members, leader and description.
